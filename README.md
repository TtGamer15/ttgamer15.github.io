# TtGamer15 Games

All of TtGamer15's games in one app. Swipe to pick a game, then tap Play.

Play: https://ttgamer15.github.io/

Games:
- Noodle Bots (https://ttgamer15.github.io/noodle-bots/)
- Museum After Dark (https://ttgamer15.github.io/Museum-After-Dark/)

To add a game, add it to the `GAMES` list in `index.html` and put its cover (1040 x 1400) in `art/`.

Settings → Bring in a save takes the text from "Copy my save" in the old Noodle Bots and Museum After Dark apps.
