For Android phones, tablets and handhelds.

Installing it

  1. Tap Download the app.
  2. Open the file when it's done (or find it in Downloads).
  3. If Android says it can't install apps from here, tap Settings, turn on Allow from this source, then go back.
  4. Tap Install, then Open.

Just the games

Already using another front end, like Daijishō? Get the version with only my games, without the retro consoles, app list or home-screen setup. It's the same app with the same saves, so installing one version replaces the other.

Download just the games

Adding your retro games

  1. Install an emulator, like RetroArch.
  2. In the app, swipe to Add your games and tap Add games.
  3. Tap Add a console, pick the console, then pick the folder with the game files.
  4. Pick the emulator, and tap Add. The console shows up on the menu.
